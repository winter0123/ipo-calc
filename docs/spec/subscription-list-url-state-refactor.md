# 청약 목록 URL 상태 리팩토링 명세

## 목표

청약 기간 입력 하나를 URL에 반영하는 순수 규칙을 페이지 렌더링과 분리한다.

## 수용 기준

- `from` 또는 `to` 변경 시 반대 경계가 없으면 기존 이번 달 기본 경계를 채운다.
- 시작일이 종료일보다 뒤로 가거나 종료일이 시작일보다 앞서면 반대 경계를 입력값에 맞춘다.
- 변경한 경계 외의 기존 쿼리 값은 유지하고, 원본 `URLSearchParams`는 변경하지 않는다.
- 페이지는 기존처럼 `replace: true`로 URL을 갱신한다.
- 공모주 필터, 투자자 상태, API 호출, 표시 동작은 바꾸지 않는다.
