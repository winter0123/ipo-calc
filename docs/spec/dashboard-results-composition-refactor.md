# 대시보드 결과 조합 리팩토링 명세

## 목표

`DashboardPage`의 데이터 조회·탭 상태 조합과 탭별 결과 출력 책임을 분리한다.

## 수용 기준

- 종합 탭은 합계 카드와 모든 투자자별 집계를 유지하고, 매도 기록이 없는 투자자는 0 요약으로 표시한다.
- 투자자 3명 이하는 펼쳐 보이고 4명 이상은 접힌 상태로 시작한다.
- 증권사별·월별·연도별 결과의 레이블·금액·빈 상태가 동일하다.
- 각 탭의 loading/error 동작, 기간 검색, 탭 전환, reset 및 현재 탭 invalidation은 바뀌지 않는다.
- 결과 렌더러는 페이지 slice 내부에 두고 기존 widget 경계를 유지한다.
