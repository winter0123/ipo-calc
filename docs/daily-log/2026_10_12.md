## 이슈 및 트러블슈팅

| 항목 | 문제 | 대응 |
|---|---|---|
| 워커 정지 | 요청 제한 워커가 `Permission required`(OpenCode 자체 임시 폴더 접근)에서 멈춤, 20분 가까이 빈 대기 | `worker-read`로 화면 확인 → `orca-worker.json`에 `/var/folders/**/opencode/**` allow만 추가 → 워커 abandon·터미널 닫기 → 구현 힌트(javap 금지, 빈 등록 방식)를 spec에 더해 새 터미널로 재배정 |
| 도구 충돌 | 요청 제한이 E2E 자체를 막음(로그인 분당 20회 초과, E2E-14 429) | 실행 스크립트(E2E·스캔·스크린샷)와 가이드에 `APP_RATE_LIMIT_AUTH_PER_MINUTE=100000` 반영 |
| 가이드 오류 | 배정일시를 "날짜 선택"으로 잘못 적어 둠(앞선 일괄 치환 탓) | 배정일도 date 입력으로 바꾸고 문구 정리(#337) |
| 도구 | 스크래치패드의 E2E 실행 스크립트가 사라짐(세션 임시 폴더 정리) | 같은 내용으로 재작성. 영구 보관은 `tools/e2e`가 아니라 임시 스크립트였으므로 필요하면 `tools/`에 둘 것 |
| 알림 재전달 | 이미 처리한 worker_done이 `check`에서 다시 전달됨 | `check --ack <delivery_id>`로 확인 처리 |
