| OpenCode Zen 내부 폴백 재현 | `opencode/mimo-v2.5-free`가 다시 OpenRouter Laguna S 2.1로 내부 폴백돼 rate limit 재발, 별도로 `opencode/ling-3.0-flash-fin-free`는 "Endpoint unavailable"로 20분 무출력 | 둘 다 watchdog STALL/직접 터미널 확인으로 감지 후 다른 Zen 모델(`opencode/big-pickle`)로 최종 성공 |
| 워커 스코프 충돌(에스컬레이션) | investorName을 필수(non-optional) 타입으로 추가하니 범위 밖 테스트 픽스처 2개가 TS2739로 build 실패 — 워커가 질문으로 블로킹 | Master가 타입은 실제 API 계약대로 필수 유지, 깨진 2개 파일만 범위에 추가하도록 승인(A안). 워커가 옵션 3개를 제시하고 근거를 먼저 조사한 뒤 질문한 점이 좋았음 |
