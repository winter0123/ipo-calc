| 문제 | 원인 | 처리 |
|---|---|---|
| 신규 달력 helper import 타입 오류 | 패키지 index에서 helper 미수출 | export 추가 후 전체 검증 |
| 상세 가격 테스트가 로딩 중 조회 | 비동기 API 완료 전 label 조회 | 비동기 조회로 변경 |
| 청약 기간 기존 테스트 실패 | 상세 일정을 종료일만 노출하도록 정책 변경 | 종료일 선택 검증으로 수정 |
| backend 포맷 검사 실패 | 두 Java 호출식이 Spotless 포맷과 불일치 | 포맷 수정 후 Checkstyle·build 재실행 |
| frontend 무료 워커 중단 | OpenRouter 무료 모델 일일 한도 초과 | 워커 변경분을 보존·통합하고 남은 수정은 직접 처리 |
| 임시 워커 작업공간 잔존 | 병합 후 Orca worktree와 retained terminal이 남음 | main 대조 후 backend/frontend worktree 제거, worker-read에서 관련 terminal 종료 확인 |
| 달력 워커 완료 보고 누락 및 범위 이탈 | 첫 수정에 비선택 필터 색상 규칙이 빠지고 helper 파일까지 변경됨 | 변경을 보존한 채 무료 모델로 재지시, 범위 복구와 직접 검증 후 병합 |
| Planning 워커 OpenRouter 응답 오류 | North Mini Code 사용 중 Cohere가 `messages[59].content` 누락 오류를 반환 | 기존 partial 문서는 보존, 외부 터미널 정지 불가를 확인해 abandon/fence 후 새 worktree의 Inkling으로 같은 Task 재배정 |
| 일정 목록 1차 검토에서 단계 우선순위·건수 표시 문제 발견 | 상장일을 청약 기간보다 먼저 판단하고 `건 대기` 문구·일부 중복 상태가 남아 있었음 | 워커에 후속 수정·회귀 테스트를 지시하고 main 전체 검증 통과 후 병합 |
| 일정 follow-up task readiness timeout | 같은 terminal에 Orca 자동 `New messages` follow-up이 먼저 연결된 상태에서 중복 Task를 배정 | 실패한 중복 dispatch는 별도 변경 없이 두고 자동 follow-up에서 요구사항을 완료, 전체 회귀 후 임시 worktree 제거 |
