| 구조 결정 | 한 계정의 여러 투자자를 화면마다 따로 고르는 구조 | 헤더 "현재 투자자" 전역 선택으로 통일, 대시보드는 계정 단위 유지 |
| 숨은 결함 | 청약 목록이 모든 투자자의 청약을 섞어 보여줌 | 현재 투자자 기준으로 수정(#326) |
| 숨은 결함 | 청약 폼이 투자자 목록 로드 전에 기본값을 캡처해 투자자가 비는 문제 | 기본값 대신 제출 시 현재 투자자를 병합 |

| 도구 | `worker-start --agent opencode --model`은 모델 선택을 검증할 수 없어 거절됨 | `orca terminal create --command 'OPENCODE_CONFIG=... opencode --model ...'` 후 `worker-start --terminal`로 배정 |

## 미결·후속

- 예전 매도 데이터의 수수료/세금 의미(옛 방식)는 변환하지 않음(합계 동일, 필드 의미만 다름).
- DB `costs` 테이블은 남아 있음(필요하면 새 마이그레이션으로 삭제).
- 수익 확인 기간 필터는 화면에서 거른다(매도가 매우 많아지면 서버 조회 필요).
- 사용자 확인: 공개 달력 레이트 리밋, KIS 약관·환경변수, 파이프라인, 첫 관리자, ustockplus 약관.
