### 이슈 및 트러블슈팅

| 카테고리 | 발생 이슈 | 해결 및 조치 사항 |
|---|---|---|
| OpenRouter 한도 | 일일 무료 한도 소진으로 워커 전체 정지 | OpenCode Zen 무료 모델(`big-pickle`, `mimo-v2.6-flash-free`, `longcat-2.5-preview-free` 등)로 전환. 사용자 지시로 Nemotron 계열 제외. 같은 모델을 동시 워커 둘에 배정하지 않음 |
| 워커 정체 미감지 | 터미널이 504 타임아웃을 찍고 입력 대기인데 watchdog이 OK로 판정 | 오류 패턴에 `50[0-4]`·`Timeout Occurred`·`Streaming response failed`·`server_error` 추가, `esc interrupt` 부재가 일정 시간 지속되면 STALL(#208) |
| 잘못된 모델 ID | 존재하지 않는 모델 ID를 주면 조용히 다른 모델로 폴백 | 터미널 생성 후 `Build ·` 줄 확인을 필수로 문서화(#209) |
| 검증 명령 혼동 | `--rerun`을 여러 task와 쓰면 마지막 task에만 적용 | 여러 task는 `--rerun-tasks`. 한 번 "`--rerun` 무효"라고 잘못 말했다가 정정, 가이드에 근거 기록 |
| 완료 알림 재전송 | worker_done을 ack하지 않고 병합해 뒤늦게 오래된 알림이 재전송됨 | 받는 즉시 ack하는 것으로 운영 |
| 가이드 vs 코드 | 코드가 가이드와 다를 때 가이드를 코드에 맞추려 함 → 사용자 지적("가이드에 안맞게 코드가 작성됐으면 코드를 고쳐야지") | 되돌린 뒤 사용자가 들여쓰기는 2칸으로 결정, 가이드 개정(#213) |
| 테스트 격리 버그 | 슬롯 DB를 새로 만들어 전체 테스트를 돌리면 622개 중 17개 실패. V15 시드 증권사 14개와 테스트 하드코딩 이름이 충돌하고, 한 테스트의 tearDown이 시드 행까지 삭제(기본 공유 DB의 `securities_firms`가 0행이던 이유) | 슬롯 4에서 Master가 재현 확인(622/17/0). 프로덕션 결함이 아니라 기존 테스트 결함이라 슬롯 도입(#215)과 분리해 별도 워커에 배정, #216으로 해결(수정하자 4번째 클래스가 새로 드러나 범위 확장) |
| KIS 키 미입력 | 재개 세션에서 `.envrc`의 `KIS_APP_KEY`·`KIS_APP_SECRET`이 빈 문자열(`KIS_CANO`·`KIS_ACNT_PRDT_CD`는 채워짐, 길이만 확인). 열린 PR 0건·워커 0개·착수 가능한 SF 없음 | 워커·PR 없이 BLOCKED로 기록하고 사용자에게 보고. 키를 채우면 게이트 답변 후 Master가 1회 조회, 이후 SF-4b→5→6 순서로 진행 |
