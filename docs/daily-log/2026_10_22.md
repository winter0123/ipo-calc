## Docker 운영 배포 구성 정리

- 운영 서버는 Ubuntu 홈 노트북에서 Docker 없이 systemd 백엔드, 호스트 PostgreSQL, Caddy 정적 프런트엔드로 운영 중임을 개인 배포 가이드와 대조했다.
- 저장소에는 운영용 Compose, 터널 오버레이, 앱 Dockerfile, Jenkins 컨테이너 설정, 예전 Docker 홈 서버 설치/업데이트 및 DB 백업/복원 스크립트가 남아 있어 제거했다.
- 루트 `docker-compose.yml`의 PostgreSQL 개발 DB만 유지하고, 구형 Docker 홈 서버 안내서는 현재 배포 가이드와 충돌해 제거했다.
- 로컬 Docker에서는 ipo-calc 운영 앱 3개와 Jenkins 컨테이너 및 전용 앱 이미지를 제거했다. 사용자의 지시에 따라 운영 PostgreSQL·Caddy 볼륨도 삭제했다. 개발 PostgreSQL과 Jenkins 볼륨 및 다른 저장소 컨테이너는 유지했다.
- 호스트 PostgreSQL 백업·복원은 새 운영 방식에 맞는 절차가 아직 없어 후속 작업으로 남겼다.
- 검증: `git diff --check` 통과, `docker compose config --services`에서 `postgres`만 확인. 자동 테스트는 실행하지 않음.
