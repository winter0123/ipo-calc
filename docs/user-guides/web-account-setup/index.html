Epic 13 · Web Account Setup

공모주 투자 수익 관리 웹 계정 설정

이 가이드는 공모주 투자와 투자 수익 관리를 시작하기 전 사용하는 웹 서비스의 계정 설정 화면을 안내합니다. 로그인으로 기존 계정에 접속하고, 회원가입으로 새 계정을 만든 뒤 투자자 등록 단계로 이어집니다.

대상 경로: /login, /signup 확인 크기: 데스크톱 1280px · 모바일 390px 오프라인 HTML

목차

  • 1. 로그인
  • 2. 회원가입

1. 로그인

기존 계정으로 웹 서비스에 접속하는 화면입니다.

화면의 목적

등록한 이메일과 비밀번호로 인증합니다. 인증에 성공하면 서비스의 대시보드(/dashboard)로 이동합니다.

입력 및 검증: 이메일은 필수이며 올바른 이메일 형식이어야 합니다. 비밀번호는 필수이며 8자 이상이어야 합니다.

주요 입력 필드

  • 이메일: 계정 등록에 사용한 이메일 주소
  • 비밀번호: 계정 생성 시 설정한 8자 이상 비밀번호
사용 흐름
  1. 이메일과 비밀번호를 입력합니다.
  2. 로그인을 선택합니다.
  3. 인증이 완료되면 대시보드로 이동합니다.
로그인에 실패하면 잘못된 계정 정보 또는 네트워크 연결 상태를 화면의 안내 문구로 확인하세요. 비밀번호는 화면에 노출되지 않는 비밀번호 입력 칸에 입력합니다.

2. 회원가입

새 계정을 만들고 투자자 등록 단계로 연결하는 화면입니다.

화면의 목적

이메일, 비밀번호, 이름을 입력해 새 계정을 생성합니다. 가입이 성공하면 계정 정보를 가진 투자자 등록 화면(/investors/register)으로 자동 이동합니다.

입력 및 검증: 이메일은 필수 및 이메일 형식, 비밀번호는 8~72자이면서 문자·숫자·특수문자 중 최소 2개 종류를 포함해야 합니다. 이름은 필수이며 2~50자여야 합니다.

주요 입력 필드

  • 이메일: 로그인과 계정 확인에 사용하는 주소
  • 비밀번호: 8~72자, 문자·숫자·특수문자 중 2개 이상 종류
  • 이름: 투자자 등록 단계에서 사용할 2~50자 이름
사용 흐름
  1. 세 필드를 모두 입력합니다.
  2. 가입하기를 선택합니다.
  3. 계정 생성이 완료되면 투자자 등록 화면으로 이동합니다.
이미 사용 중인 이메일은 중복 가입으로 처리됩니다. 입력값을 다시 확인하거나 다른 이메일 주소를 사용하세요.
