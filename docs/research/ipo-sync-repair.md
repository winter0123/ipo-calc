## DART HTML 렌더링 vs document.xml 차이점

| 구분 | HTML 렌더링 (section-*.html) | document.xml |
|------|------------------------------|--------------|
| **정정 표시** | `<SPAN style='font-weight:bold;color:#FF0000;'>` 인라인 스타일 | 별도 `<수정전>`, `<수정후>` 노드로 구조화 |
| **표 구조** | 중첩 TABLE, COLGROUP, ROWSPAN/COLSPAN 혼용 | 플랫한 요소 트리 |
| **가격/총액 구분** | 같은 행의 다른 `<TD>` 컬럼 (모집가액 vs 모집총액) | 별도 필드 요소 |
| **주석(주N)** | `<TABLE class='nb'>` 내 `<TD>`에 텍스트 포함 | 주석 전용 요소 |
| **BR/SPAN** | 줄바꿈 `<BR/>`, 강조 `<SPAN style=...>` 보존 | 텍스트 노드에 병합될 수 있음 |

**파서 구현 시 고려사항**:
1. HTML은 렌더링 후 시각적 구조이므로 `Jsoup`로 파싱 시 스타일 속성(`color:#FF0000`)로 정정 후 값 식별 가능
2. `document.xml`은 정정 전/후가 구조적으로 분리되어 있어 더 정밀한 파싱 가능
3. 현재 프로젝트는 HTML 렌더링 기반 파싱 사용 중 → SPAN 스타일로 정정 후 값 추출 로직 필요
